# Sawyer Jacobson — Research Portfolio

Source for [sawyerjjmath.github.io](https://sawyerjjmath.github.io), an interactive archive of research in differential geometry, geometric flows, minimal surfaces, and partial differential equations.

## Development

Requires Node.js 22 or newer.

```bash
npm ci
npm run build:pages
```

The static export is written to `out/`. Pushes to `main` deploy automatically through GitHub Actions.
